# Demo (Part 10, sections A and E)

## A. The golden run (acceptance test for the whole product)
A judge opens the URL in a clean browser profile, laptop or phone, no login.
1. Within 10 seconds a bundled dead sample is on screen as dim bytes, with one button: Resurrect.
2. They press it. The six beats play. Content assembles row by row from the bytes, glowing in the accent colour; uncertain rows flicker amber, then settle; the Confidence Grid lights up.
3. They click any part of the result. The matching bytes light up, a line connects them, a panel shows the rule and confidence.
4. The verification report shows the result against the reference: exact match, zero mismatches, the blind-test file clearly labelled.
5. They load a corrupted copy. The system ends as unrecovered, in failure red, with the reason in plain words, without a crash.
6. Nothing depends on luck, and reduced-motion mode shows the same information.
