# Tech: pipeline (Part 3) and decisions D-01 to D-15

Everything runs in the browser. No backend, no accounts, no runtime AI. AI's job is build time: write and tune detectors against the corpus. UI talks to a Web Worker so analysis never freezes animation. Same input gives same output.

## Pipeline
1. Analyzer: generic detectors (headers, run-length patterns, repeated structures, table-like regions, palettes) output ranked hypotheses with supporting byte ranges and, for rejected ones, why they lost.
2. Recoverer: best hypothesis to content plus self-checks. Every element carries evidence: byte range(s), rule, confidence 0 to 1.
3. Verifier: compares with the bundled reference: exact or not, plus mismatch list. No reference (user file): "no reference available", evidence and confidence only.

Evidence type:
```ts
type Evidence = {
  elementId: string;
  byteRanges: ReadonlyArray<{ start: number; end: number }>; // start inclusive, end exclusive, inside file
  rule: string;         // plain words
  confidence: number;   // 0 to 1
  hypothesisId: string;
};
```

## Locked decisions
- D-01 Format: PCX; MacPaint fallback only if the Gate 0 spike fails. Samples generated by us (Pillow or ImageMagick, build time only) from our own images; at least 10, starting with 8-bit palette; other depths only after Gate 1. Inference layer stays format-agnostic; the format name appears only in corpus metadata, demo config and the labelled decoder.
- D-02 Runtime: static, browser-only. No server code (no API routes, middleware, server actions), no database, no accounts, no network or AI calls at runtime.
- D-03 Stack: TypeScript strict; Next.js App Router with `output: 'export'`; React; Web Workers; Canvas 2D, SVG, CSS 3D; Three.js for the optional L0 layer only; Vitest; fast-check; Playwright with axe (plus Playwright MCP for screenshots; no custom MCP server, use `npm run inspect -- <file>`); Lighthouse CI; Node LTS; npm with lockfile; exact versions pinned.
- D-04 3D: CSS 3D, Canvas 2D, SVG carry the UI; text, hex, evidence lines, Confidence Grid never move into WebGL. One optional lazy Three.js layer for L0 only (T-20): loaded after interactive, chunk under 200 KB gzipped, 55 fps or better, fallback to Canvas 2D when WebGL missing or fps under 45, paused when tab hidden, off under reduced motion, switchable off for tests. If any condition fails, drop it; never loosen a budget.
- D-05 Hosting: Vercel production plus preview deploys as staging. Security headers in vercel.json (static export ignores next.config headers). Optional Cloudflare Pages mirror.
- D-06 CI: GitHub Actions runs `npm run verify` on every push and PR. Production deploys only from main and only when green.
- D-07 Network: no analytics, no third-party scripts, fonts self-hosted. CSP as strict as a static export allows (`connect-src 'self'`, no remote origins, no framing). Record every relaxation and reason in docs/security.md.
- D-08 License: MIT, copyright Parth Radheshyam Laturiya. Added at T-24 at the latest; visible in repo About before submit.
- D-09 Errors: error boundary and local error panel. No third-party service.
- D-10 Budgets: 1 MB file analysed under 3 s in a worker; bundled sample to visible result under 10 s on a mid-range laptop; initial JS under 250 KB gzipped (excluding lazy Three.js chunk); Lighthouse performance 90+ on landing; animation 55 fps+.
- D-11 Input limit: 10 MB maximum.
- D-12 Fonts: Inter and JetBrains Mono, open-licensed, self-hosted.
- D-13 Git: work on main with short-lived branches. Commit before and after every task, message `T-xx: summary`. Signed commits. Tags `rc-N` and `good-N` on known-good deploys.
- D-14 Dependencies: prefer none. Add one only with a one-line reason and its size cost. Charts are hand-built SVG.
- D-15 Dates: Gate 0 Thu Nov 26. Gate 1 Sun Nov 29. Gate 2 Tue Dec 1. Gate 3 (feature freeze) Wed Dec 2. Submit by noon IST Fri Dec 4. Hard deadline 2:00 PM PT Dec 4 (03:30 IST Dec 5). Credit requests close 12:00 PM PT Dec 1; unredeemed codes expire Dec 4; redeemed credits expire Dec 31.
