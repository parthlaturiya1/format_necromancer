# R-1: design review of T-13 (shell vs design target)

Reviewer: design-only, wrote no code. Inputs: `docs/design-target.png` (2400x1350), `t13-desktop.png` (1440x900), `t13-phone.png` (390x2135), `src/ui/shell.css`, `src/ui/tokens.css`, `.kiro/steering/design.md`. Measurements below are read from the PNGs, scaled to 1440 wide where compared. Experience specs were not re-read in full; findings are checked against design.md and the CSS.

## 1. Verdict
Clean, correct and accessible, but it reads as a dim wireframe: the first 10 seconds show no colour, no call to action and no depth, so it loses to the target before any engine work is visible.

## 2. Findings, ranked by first-10-seconds impact

**F1. The empty state has no button.** Where: Recovered image panel, `.image-stage`. Target: n/a (target is mid-run), but the headline "Drop a file nothing can open, or resurrect a sample" promises two actions. Build: text only, no control. A judge cannot start the demo. Fix: add under `.empty-sub`, 24 px gap (`--sp-5`): primary pill "Resurrect a sample" (`.btn`, accent fill, 44 px high, `--fs-base`, weight 600) and ghost pill "Choose a file" (`.btn.ghost-btn`). Keep the whole dashed zone a drop target; on drag-over set border to `color-mix(in srgb, var(--accent) 60%, transparent)` and the radial to 14%. Task: T-14 now (shell) with T-16 wiring.

**F2. Hex is too dark to read as bytes, and shows 8 columns, not 16.** Where: `.hex`, `.hex-bytes`. Target: 16 bytes per row, bytes at roughly #6B7385 (about 4:1 on the panel), offsets a notch dimmer, 20 rows, byte text about 0.85% of width. Build: bytes use `--unexplained` (muted at 38%, about 1.9:1), offsets `--muted` at 0.55 opacity (about 2.3:1), and the container query `@container (max-width: 560px)` fires because the Bytes panel is about 555 px wide at 1440, so it drops to 8 columns and spreads them across the panel. Fix: dormant bytes `color: color-mix(in srgb, var(--muted) 62%, transparent)` (about 3.8:1; define as a new token in `tokens.css`, e.g. `--byte-idle`, not inline); offsets 0.7 opacity; move the container breakpoint to 480 px so 1440 gets 16 columns; `.hex-bytes` gap `--sp-2` and `justify-content: start` with fixed `2ch` cells, so the grid looks like a dump, not a table. Task: T-14 panels.

**F3. Panels barely separate from the background (glass depth).** Where: `.panel`. Target: panel fill clearly lighter than page (about #12151D vs #07080C), crisp 1 px border, and a visible teal ambient glow behind the centre panel. Build: fill is 6% to 4% white, border 8%, and the L0 bytes are so faint that the 18 px blur has nothing to blur, so it looks flat. Fix: keep `--glass-fill` and `--glass-border` as tokens; in `.panel` raise the gradient start to `color-mix(in srgb, var(--text) 9%, transparent)` over the first 38%; raise the L0 byte alpha so bytes show at panel edges (about 0.10 to 0.14, only some brighter ones at 0.22); add one body-level radial `radial-gradient(50% 45% at 50% 42%, color-mix(in srgb, var(--accent) 6%, transparent), transparent)` over `--bg-1`. Task: T-14 now.

**F4. Panel spacing is too tight compared with the target.** Where: `.stage` gap, `.app` gaps. Target: gutters between panels about 4% of width (about 58 px at 1440), panel inner padding about 40 px at 2400 (24 px at 1440), generous space under the header. Build: gap is `--sp-5` (24 px), panels nearly touch, header-to-content gap is `--sp-4`. Fix: `.stage { gap: clamp(var(--sp-5), 2.6vw, var(--sp-7)) }` (24 px to 48 px, about 37 px at 1440); `.panel { padding: var(--sp-5) var(--sp-5) }` stays; header `margin-bottom: var(--sp-3)`; HUD column gap `--sp-4` so the three HUD cards read as one group, wider than the outer gutters. Task: T-14 now.

**F5. HUD cards are empty rectangles; the phone and desktop waste the right edge.** Where: `.col-hud` (Confidence grid, Confidence by row, Verification). Target: lit dot grid, area chart with glow, a ringed selected dot. Build: 126 hollow rings, a dashed flat line, a muted grey "0". Fix for the empty state specifically: draw the grid at 5 rows x 14 with 3 to 4 rings gently pulsing in sequence (`.pulse`, opacity only, `--dur-3`, stagger 120 ms) so it looks alive; replace the dashed flat chart with a 3-line axis plus the text "Appears after Resurrection" in `--fs-xs` muted; Verification "0" keep, but add a 5 px `.bar` in accent at 0%. For filled states: dots 12 px (not 10), accent dots get `box-shadow: 0 0 10px color-mix(in srgb, var(--accent) 55%, transparent)`; chart area `linear-gradient(accent 35%, transparent)`, line 1.5 px with `drop-shadow(0 0 6px accent 50%)`. Task: T-17 HUD (empty-state tweaks T-14 now).

**F6. Timeline gives no sense of place.** Where: `.timeline`. Target: finished steps are filled mint dots, current has a 16 px ringed glowing dot and mint label, future are hollow and dim; labels 13 px. Build: six identical 11 px hollow dots, all labels muted; on phone labels are hidden and only six unlabeled dots remain. Fix: add `data-state="done|current|todo"` styles: done `background: var(--accent)`; current 16 px, `box-shadow: 0 0 0 4px color-mix(in srgb, var(--accent) 22%, transparent), 0 0 18px var(--accent)`, label `var(--accent)` weight 600; todo as now. Connect the line: done segment `var(--accent)` at 60%. In the empty state mark "Dead file" as current. On phone show only the current label under the dots (centered, `--fs-sm`), set `aria-current="step"` on it. Task: T-14 now (markup/state), T-16 drives it.

**F7. The image panel's ghost is small and sits under a 3-line headline.** Where: `.ghost`, `.empty-title`. Target: ghost about 15% of canvas width, solid mint, the hero of the panel. Build: ghost about 8% of width (`min(40%, 9rem)` = 144 px max), the headline (36 px, three lines) is the strongest element and pushes the ghost up. Fix: ghost `width: min(52%, 12rem)`; headline `--fs-lg` to `--fs-xl` but `max-width: 22ch` so it wraps into 2 lines at 1440; keep `em` in accent. The ghost's `drop-shadow` rises to 36 px at 22% accent. Task: T-14 now.

**F8. Footer is unbalanced and wastes the brand line.** Where: `.foot`. Target: two stacked left lines, the second in mint: "Runs in your browser. Nothing is uploaded." then "Recovered without the format specification." (R-U4 text lives in the left column), plus one short right note. Build: left has one line with a dot; right is a two-line 13 px muted credit that wraps at 58ch, baselines misaligned (846 vs 856). The credit competes with L0 byte noise behind it. Fix: `.foot { align-items: end }`, credit `max-width: 72ch` so it fits one or two lines at the same baseline, colour `--muted`, `--fs-xs`; add the mint second line on the left once the run is complete (the exact copy is already asserted in tests; do not change it). Task: T-14 now (alignment), T-16 (mint line on completion).

**F9. Phone: order and length.** Where: `.stage` below 760 px. Build: 2135 px tall; first screen is dim hex, the image comes at about 600 px, HUD last. Target intent is "hero first". Fix: order Recovered image first, then Bytes, then Region, then a 2 column HUD (Confidence grid + Verification side by side, 8 px gap `--sp-3`), hide the empty "Confidence by row" until data exists. Brand: allow title one line at 18 px (`--fs-md`) and drop the file line under it to `--fs-xs`; the Speed pill gets 40 px height min (tap target 44 px recommended). Result should be under 1500 px. Task: T-14 now (order via `order`), T-17 (HUD grouping).

**F10. Title scale and the author's gap 5 are partly wrong.** Where: brand h1. Measured: target "Format Necromancer" spans 12.7% of canvas width, build spans 15.2%, so the build title is already larger than the target, not smaller. Panel titles are also larger (1.18% vs 0.92% of width). Do not scale the title up. Instead fix weight contrast: subtitle `--fs-sm` muted is fine; the missing hierarchy cue is the panel meta text (accent "Hypothesis 1 of 3..." in the target). Keep meta right-aligned and use `.meta.live` accent from T-16 on. Task: none for scale; T-16 for live meta.

## 3. Keep list (better than the target)
- Empty-state headline with a mint "resurrect a sample" and `text-wrap: balance`. The target has no headline at all.
- Honest, instructive empty copy ("No region selected. Pick bytes or a row...", "Rows rebuilt 0 of unknown"). Better than the target's mid-run text for a first-time judge.
- Dashed drop zone with a soft accent radial: clear affordance (add the button, F1).
- Tabular numerals and a container query on the panel, so the hex responds to panel width, not viewport. Keep the mechanism; only move the breakpoint (F2).
- Mask fade at the bottom of the hex list (smoother than the target's hard cut).
- Glowing footer lock dot; the logo glow (`.logo` box-shadow) is subtler than the target's.
- `:focus-visible` 2 px accent ring with offset, reduced-motion block, axe 0 violations on three pages, no horizontal scroll on phone.
- Panel inset highlight (`inset 0 1px 0`): a nice top edge. Keep it when raising fill (F3).

## 4. Rule breaks and risks (read from CSS)
1. **Contrast, `src/ui/shell.css` `.hex` / `.hex-off`.** Idle bytes about 1.9:1 and offsets about 2.3:1 against design.md "readable contrast". Axe passes only because the rows are `aria-hidden` (decorative). When T-14 makes bytes real and focusable this becomes a violation. Fix as F2.
2. **Off-scale sizes, `shell.css`.** `.chart text { font: 400 10px }` is below `--fs-xs` (12 px) and is rendered in a scaled SVG; use `font-size: var(--fs-xs)` or size the viewBox so the rendered size is at least 12 px. Also raw px with no token: logo 44 px, timeline dot 11 px, legend 10 px, dots 10 px, bar 5 px, `.verify .big-num { 2.5rem }`. Not colour breaks, but design.md says "no ad-hoc styling elsewhere": move recurring ones to tokens (`--dot-size`, `--bar-h`) at T-14.
3. **Colours: no raw hex or rgba found outside `tokens.css`** in `src/**/*.css` and `src/**/*.tsx` (grep for `#rrggbb`, `rgb(`, `rgba(`). L0 canvas `ink` is a variable, source not read here.
4. **Motion: compliant.** Only `.pulse` (opacity) and `.btn` (transform, `--dur-1`, `--ease-out`); both are switched off under `prefers-reduced-motion`. Note `.btn:hover` adds `box-shadow` transition, which design.md's "transform and opacity only" does not cover; drop `box-shadow` from the `transition` list and animate an opacity glow pseudo-element instead.
5. **Perf risk.** `backdrop-filter: blur(18px)` is on 7 elements (6 panels + Speed pill) over a live canvas. Not measured; check frame rate when T-16 animates, and drop blur on small panels (inspector, Speed pill) if it drops below 50 fps.
6. **Accessibility gap.** Timeline has no `aria-current`; on phone its labels are clipped away. Fix with F6.

Not checked: real-device rendering, the L0 canvas source, contrast values measured by tool (estimates above are from pixel colours and token maths, accurate to about 0.3).
